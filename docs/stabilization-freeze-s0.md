## 1. 冻结范围

### ❌ 禁止（硬性冻结）

| 类型 | 说明 |
|------|------|
| 新增功能 | 任何新 feature，包括小的 |
| 新增菜单/权限 | 新增 MENU_* 或 rbac.matrix 条目 |
| 新增模块 | 新建 NestJS module 或前端独立页面 |
| 新增数据库表/迁移 | 任何 DDL（除紧急 P0 热修） |
| 修改库存体系 | inv_batches/inv_ledger/FIFO/packaging 逻辑 |
| 修改销售体系 | Sales V2 订单/配送/退货/POS 业务链路 |
| 修改财务体系 | AR/收款/现金账户逻辑 |
| 修改追溯体系 | TraceabilityModule |
| 修改权限架构 | rbac.matrix 角色权限调整 |

### ✅ 允许（受控修改，须经 DBA/PM 审批）

| 类型 | 说明 |
|------|------|
| **P0 Bug 修复** | 数据正确性/权限漏洞/系统崩溃 —— 优先级最高，立即修复 |
| **P1 Bug 修复** | 流程卡死/关键功能不可用 —— 24h 内修复 |
| 权限错误修正 | 用户权限不正确（不改架构，只改数据） |
| 性能优化 | 慢查询加索引、N+1 修复 —— 不改业务逻辑 |
| 日志增强 | 添加诊断日志，不影响功能 |
| 部署/基础设施 | CI/CD、nginx 配置、Docker 配置 |
| UI 小修 | 文字对齐、颜色、间距 —— 不涉及业务状态 |
| 文案修正 | 错别字、标签不准确 |
