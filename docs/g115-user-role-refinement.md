- `sys_user_role`：每人「全删旧角色 + 按终审重插」，首个=主角色；按 username/role_code 解析；幂等。

- 本地缺账号（tangzhiwen/xuefeng/langshipei/cashier 等）JOIN 自动跳过；生产端全量生效。
- 本地验证：DELETE 37 / INSERT 39 角色；归属 DELETE 2 / INSERT 2（林宏/伏强；阿玉本地无账号）。
