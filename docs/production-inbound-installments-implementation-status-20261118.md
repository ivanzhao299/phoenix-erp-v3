- 实际日报来源、占栏、分级量、保护附件摘要与不同登记/接收人签认绑定。多班次分段分配，按 grade 跨规格汇总额度。实物交接未过账时可按差异证据废止、显式引用前驱重签；已过账交接禁止废止复用。
- 原单分段冲销、累计上限、来源补偿、独立业务审批、独立财务核验、原/当前期间版本与证据复核。成本 UNKNOWN 与真实确认 0 区分；冲销不把未知成本计为 0。同一财务核验摘要重试返回同一签认。
- 库存资格公共谓词接入共享分配、WMS、销售、POS、库存/估值与部分 BI 查询；数据库触发器保护直接库存及流水写入，归档根不能经子批或身份改写进入正式库存。SUSPENDED 保留查询并拒绝新操作。未关联批次的历史流水保留。
- 新增响应式正式入库页面与三语文案，复用鸡舍/仓/库位/规格选择器和上传组件；接入实物交接、历史、草稿/回执、冲销与财务/业务审批。日报对正式鸡舍提供运行时班次字典。旧页面提示正式入口，服务端继续拒绝旧 DAILY 写正式域。
- 采购确认保存稳定的收货行身份。批准仓域外的无关采购保持原行为；实际调入正式域才重新核验 CONFIRMED 原行、商品与基本单位，准入采购根和派生批。实际采购→调拨→共享 FIFO 与未知单位整单回滚已用 PG 验证。跨公司资格转移仅允许内部 WMS 路径，混商品或未允许的 SKU 变化拒绝。
- 受限缺陷按实际库存处置，不能把 `qty_available=0` 当作没有实物。调拨保留 QUARANTINE/DAMAGED、DEFECT_SALE、品种、来源档案和根；归档源整单回滚。库存/财务 BI 提供成本待确认数量，存在待核成本时完整估值为 NULL。
- 抽出同一工作台到 PC 和真正的 `/mobile/production-inbound` 布局，提供生产权限的受控库位 lookup、按交接号跨设备恢复、暂存交接恢复、审批分段和财务附件查看。
- 增加独立只读正式审计：以不可变 POSTED 行/分配/原流水核算净额度和回执，支持销售减少当前库存。读事务为 REPEATABLE READ/READ ONLY；PASS 不能作为发布准入，也不替换原全库审计 HOLD。固定 60 枚 CLI apply 明确退役，初始化数据库前拒绝。
