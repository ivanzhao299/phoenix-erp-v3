## 3. Runner Capability

Runner path:

`scripts/ops/agent-inbox-runner.mjs`

Supported modes:

```bash
node scripts/ops/agent-inbox-runner.mjs --dry-run
node scripts/ops/agent-inbox-runner.mjs --execute-approved
node scripts/ops/agent-inbox-runner.mjs --parallel 4
node scripts/ops/agent-inbox-runner.mjs --no-remote-write
```

Safety behavior:

1. Defaults to dry-run unless `--execute-approved` is used and a matching active approval exists.
2. Reads approval records from `APPROVALS.md`.
3. Writes route artifacts to `docs/ops/runs/`.
4. Writes user-facing result to `OUTBOX.md`.
5. Does not write DB, run migration, deploy, restart, push, modify business code, or mutate remote server state.
