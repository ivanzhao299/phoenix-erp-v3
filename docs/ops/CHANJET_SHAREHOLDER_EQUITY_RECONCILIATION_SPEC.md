# 好业财股东权益会计对账规范

## 1. 管理目标

ERP 负责股东名册、项目股权结构、认缴与实缴业务事实；好业财负责已经入账的会计事实。两端通过公司账套、股东科目和逐笔凭证勾稽形成可解释的差异，不互相静默覆盖。

## 2. 权威来源

| 业务事实 | 权威来源 | 对账对象 |
| --- | --- | --- |
| 股东身份、项目股权比例、认缴与法定实缴 | ERP `shr_shareholders`、`shr_project_equity` | 好业财 4001 子科目余额 |
| 逐笔股东出资 | ERP `shr_capital_contributions` 中股权类记录 | 好业财凭证 4001 行 |
| 股东借款、垫资、代付、清偿 | ERP 股东资金往来台账 | 好业财其他应付款/其他应收款等往来科目 |
| 已记账实收资本 | 好业财 4001 科目及其子科目 | ERP 法定实缴与逐笔股权出资 |
| 会计凭证 | 好业财凭证与凭证明细 | ERP 业务单据和 ERP 凭证草稿 |

`fin_shareholder_contributions` 不等同于法定股权出资。`SHAREHOLDER_ADVANCE`、`GOODS_PAYMENT`、`PERSONAL_PAYMENT` 等借款、垫资和代付不得计入 4001 实收资本。

## 3. 映射层级

1. `company_code` 对应唯一启用的好业财账套。
2. `shareholder_code + company_code + currency` 对应好业财 4001 子科目。
3. `contribution_no` 对应好业财凭证中的唯一 4001 行。
4. ERP 收款账户对应好业财现金或银行科目，只有批准映射后才能生成凭证草稿。
5. 名称相似只生成候选，不能自动成为已批准映射。

## 4. 对账状态

- `OK`：金额、期间、公司、币种和逐笔勾稽均一致。
- `MISMATCH`：同口径金额存在差异。
- `NEED_MAPPING`：缺少公司、股东科目或账户映射。
- `NEED_MANUAL_REVIEW`：存在多候选、币种拆分、历史归属差异或证据不足。
- `HOLD`：禁止月结或生成凭证草稿。

差异必须展示 ERP 值、好业财值、差额、期间和证据来源，禁止用零、旧快照或名称猜测掩盖。

## 5. 月结条件

每家公司每月必须同时满足：

1. 股东到 4001 子科目映射覆盖率 100%。
2. ERP 法定实缴与好业财 4001 本位币余额差额不超过 0.01。
3. ERP 法定实缴与股权类逐笔出资内部差额不超过 0.01。
4. 当期应勾稽的股权类出资全部关联唯一凭证行。
5. 借款、垫资、代付已经从股权口径隔离。

任一条件不满足即 `HOLD`。关闭期间只保存 ERP 对账证据，不写好业财。

## 6. 凭证草稿边界

ERP 可以基于已确认股权出资生成内部凭证草稿：借记已批准现金/银行科目，贷记已批准 4001 股东子科目。草稿必须借贷平衡、带来源单号和幂等键。

当前外部写入开关保持关闭：

- 不调用好业财新增、修改、删除或凭证推送接口。
- 不允许自动过账。
- 不允许把借款、垫资或待复核记录生成实收资本凭证。
- 未来写回必须另行批准准确账套、单据、金额、端点、幂等键和回滚方式。

## 7. 权限与审计

- 查看：`MENU_SHAREHOLDER_CAPITAL:V`，并受 DataScope 公司范围限制。
- 映射确认、逐笔勾稽、ERP 草稿和月结：`MENU_SHAREHOLDER_CAPITAL:A`。
- 写操作必须携带对应显式确认令牌，并重新在服务端验证候选和公司范围。
- 超管不绕过审计；每次确认写入 `chanjet_reconciliation_results`。

## 8. 当前已知差异

只读审计基线显示 ERP 法定实缴合计 `91,588,736.12`，好业财 4001 合计 `98,443,307.79`，差额 `6,854,571.67`。主要来源包括期间截止差异、直营店投资未归属股东、同一股东按币种拆分，以及星驰项目股东内部归属不一致。这些差异保持 `HOLD`，不得自动改动任一端数据。
