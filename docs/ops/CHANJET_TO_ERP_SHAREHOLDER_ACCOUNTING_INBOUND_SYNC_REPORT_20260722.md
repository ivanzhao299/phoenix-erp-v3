# 好业财到 ERP 股东会计事实入站同步报告

## 结论

`GO WITH CONDITIONS`。

已实现“好业财只读权威源 → 逐项核对 → ERP 会计镜像”的单向同步。该链路只写 ERP 新增的会计镜像与映射审计表，不写、删、改好业财，也不覆盖 ERP 法定股权、逐笔出资或资本流。

## 权威边界

| 数据 | 权威来源 | 同步策略 |
| --- | --- | --- |
| 法定股东、认缴、实缴登记 | ERP `shr_shareholders` / `shr_project_equity` | 不被好业财覆盖 |
| 逐笔出资与审批状态 | ERP `shr_capital_contributions` | 不被好业财覆盖 |
| 已记账实收资本 | 好业财 `4001` 及子科目 | 核对后写入 ERP 会计镜像 |
| 借款、垫资、代付款 | ERP 股东往来 | 不计入 `4001` 实收资本 |
| 未识别非个人账户 | 好业财源事实 | 保留为 `SOURCE_ONLY`，不绑定股东 |

## 实现范围

1. 新增 `chanjet_shareholder_accounting_balances`，保存好业财已记账会计事实、原科目名、ERP 对应、核对依据、源哈希与批次。
2. 新增 `chanjet_erp_inbound_sync_runs`，保存计划哈希、来源数量、匹配数量、保留项、写入数量与操作者。
3. 新增只读预检、最近批次和显式同步 API。
4. 好业财四小时只读镜像任务完成后自动刷新 ERP 会计镜像；核对 HOLD 时不写入。
5. 对账页展示每个科目的名称、金额、对应对象、置信度、理由与阻断项。
6. 对账读取优先使用 ERP 会计镜像，尚未建立镜像时才回退到好业财只读快照。

## 安全与一致性

- 好业财外部写：`false`。
- ERP 法定股权覆盖：`false`。
- 冲突策略：整批 `HOLD`。
- 计划漂移：`planHash` 不一致拒绝写入。
- 幂等：同一 `planHash` 重复执行返回原批次。
- 新鲜度：源镜像超过 8 小时拒绝写入。
- 完整性：每个账套必须有唯一 `4001` 父科目、子科目明细且父子金额差不超过 `0.01`。
- 非个人账户：完整保留，禁止伪造股东对应。
