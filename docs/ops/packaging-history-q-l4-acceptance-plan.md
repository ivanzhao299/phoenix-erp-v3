# 包装历史 Q/L4 现场验收准备

本文件是现场验收准备清单，不是现场事实、生产批准或正式标签发行记录。当前 Q/L4 尚未完成，`PKG_HISTORY_POLICY` 保持默认全关。

## 验收清单与证据

| 项目 | 必留证据 | 判定 |
|---|---|---|
| 设备出纸 | 打印请求号、设备编号、纸张/DPI、原始标签照片、时间戳、操作人 | 请求成功且纸张内容与请求一致 |
| 标签实贴与扫码 | 标签照片、扫码原文/脱敏摘要、箱码、canonical/legacy namespace、时间戳、操作人 | 实贴箱码可扫码，解析到唯一箱身份 |
| 箱数与数量核对 | 原包装单号、原产出/当前数量、箱数盘点表、复核人和时间戳 | 原始入账量、箱数、ledger 对账一致；不得自动补余 |
| 接收人事实 | 接收人身份、授权范围、交接单号、签名/确认记录、时间戳 | 接收人和公司/场/仓库范围匹配 |
| 仓库/库位事实 | warehouse、zone、location 编码，现场照片或系统截图，时间戳、操作人 | 编码存在且与 DataScope/现场一致 |
| 交付与签收 | 交付单/签收单号、双方操作人、时间戳、扫码记录、异常说明 | 一次确认与证据链可回放，异常不得标记成功 |

证据文件应使用专属编号，照片/扫码记录不得包含密码、token 或完整个人敏感信息。每条记录至少包含 `evidenceRef`、`capturedAt`（含时区）、`operator`、`sourceDocument` 和脱敏摘要。

## 判定与旗标关系

所有清单项必须通过，且软件只读/事务/幂等回归没有红灯，才可提交 Q/H 启用审批。`Q` 不能由布尔值单独成立；必须提供独立物理资格记录：`qualification.accepted=true`、非空 `evidenceRef`、可解析的 `acceptedAt` 以及设备 profile。`H` 只有在 `R+B+P+V` 全为 true 且 Q 资格有效时才可为 true。任何缺证、UNKNOWN、partial 或扫码失败均保持关闭。

现场事实完成前不发行正式 PBX/包装标签；本文件本身不产生资格。
