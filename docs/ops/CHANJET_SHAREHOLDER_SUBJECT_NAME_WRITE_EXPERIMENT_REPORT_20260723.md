1. 目标账套、科目编码和当前名称与批准清单完全一致。
2. 修改后官方科目列表返回核准名称。
3. 科目 ID、父级、分类、借贷方向、末级状态和余额结构指纹保持不变。
4. 任一读回不一致即判定 HOLD，不接受页面提示或网关回执代替持久化证据。

## 4. 登录与持续同步边界

- 正常的好业财只读同步使用生产 API 容器中的应用凭证、`appTicket` 和 token 生命周期管理，不依赖浏览器登录，不需要每次人工登录。
- 本次属于“已使用科目强制改名”的罕见管理员修正。公开 OpenAPI 没有可验证的强制持久化参数，因此才使用官方业务页面。
- 好业财业务页面的公司切换与 SSO 会话由供应商控制；浏览器会话过期、切换组织或跨企业工作台时可能要求重新登录。
- 不保存用户密码、浏览器 cookie 或会话 token，不用持久化个人登录绕过供应商认证。
- 后续常规同步继续自动运行；只有供应商 OpenAPI 无法完成且用户单独批准的高风险管理修正，才进入官方 UI 人工 Gate。
