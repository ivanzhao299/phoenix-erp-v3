# 好业财商品名称单行修正执行 Gate 报告

日期：2026-08-04
结论：`HOLD_PROVIDER_API_PERMISSION`

## 1. 批准范围

本次批准仅覆盖一个低风险商品名称修正，不包含其他候选：

| 字段 | 值 |
|---|---|
| mapping id | `307052` |
| 好业财账套 | `3537748712226818` |
| 商品编码 | `0100005` |
| 好业财内部商品 id | `3557635884849011` |
| 原名称 | 阿莫西林可溶性分 |
| 目标名称 | 阿莫西林可溶性粉 |
| 修改范围 | 仅商品名称 |

禁止修改商品编码、计量单位、规格、库存事实、财务事实或其他商品。

## 2. 来源证据

- `chanjet_master_mapping.id = 307052` 当前为 `SOURCE_ONLY / APPROVED`。
- 好业财只读库存快照中的商品编码为 `0100005`，商品名称为“阿莫西林可溶性分”。
- 同一来源对象在即时库存、批次即时库存和材料出库数据中保持一致。
- 快照提供的好业财内部商品 id 为 `3557635884849011`，可用于精确定位，未依赖模糊名称匹配。

## 3. 官方 API 合同

通过好业财开放平台官方 API 目录确认：

| API id | 名称 | 方法与路径 | 用途 |
|---|---|---|---|
| `31146` | 查询商品 | `POST /accounting/document/open/product/query/{bookid}` | 写前精确读取和写后回读 |
| `19953` | 批量同步商品 | `POST /accounting/document/integration/product/batchUpsert/{bookid}` | 单行商品名称修正 |

写入载荷必须保留既有 `id`、`code`、基础计量单位和规格，只修改 `name`。

## 4. Preflight 结果

1. 使用生产运行态 token 调用商品查询 API：`HTTP 403 / code 50111`。
2. 使用当前 appTicket 和证书重新生成全新 token：生成成功。
3. 使用全新 token 再次调用商品查询 API：仍为 `HTTP 403 / code 50111`。

这证明阻断不是 token 过期或本地缓存，而是当前好业财开放平台应用没有被授予商品查询 API 权限。

## 5. 安全决策

- 好业财写接口调用：**否**。
- 好业财数据修改行数：**0**。
- ERP 业务数据修改行数：**0**。
- migration：**否**。
- 部署：**否**。
- 回滚：无需执行，因为没有发生外部写入。

在无法完成写前读取、写后回读和差异验证时调用写接口，会破坏单行 canary 的可验证性。因此 Gate 按 fail-closed 原则进入 HOLD，不伪报成功。

## 6. 解除 HOLD 的准确条件

在当前好业财开放平台应用中授予以下 API：

1. `31146` 查询商品：必须，用于写前与写后官方回读。
2. `19953` 批量同步商品：必须，用于获批的单行名称修正。

授权完成后应重新生成 token，并依次执行：

1. 按账套、商品 id 和编码读取当前对象。
2. 校验当前名称仍为“阿莫西林可溶性分”，并冻结完整原始载荷作为回滚证据。
3. 单行 `batchUpsert`，仅将名称改为“阿莫西林可溶性粉”。
4. 使用 `31146` 官方 API 回读商品 id、编码、名称、规格和基础计量单位。
5. 重跑 ERP 好业财只读镜像，确认两条读取链一致。
6. 任一字段发生非预期变化时，使用冻结的原始载荷单行回滚并标记 HOLD。

## 7. 当前结论

`HOLD_PROVIDER_API_PERMISSION`

用户批准已经记录，但外部应用权限 Gate 尚未通过。恢复执行不需要浏览器人工登录；权限补齐后继续使用 API-only 流程。
