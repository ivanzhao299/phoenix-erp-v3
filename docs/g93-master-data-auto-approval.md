# G93 主数据自动审批网关 — 规则化校验取代人工审批

> 日期：2026-06-13 ｜ 用户拍板：**全自动无例外 / 名称+关键唯一键查重 / 不通过当场退回列原因**
> 一句话：主数据提交瞬间跑 5 关规则校验，全过即秒级 ACTIVE（无人工），任一不过当场退回并列出全部原因。

---

## 1. 为什么做（用户原话）

> 「如果一个数据都要由人工去审核，那不也太垃圾了吗？……客户、供应商随时可以新建，自动比对之后立马生成。」

**现状坦白**：G3-B/G92 的主数据"审批"是**纯人工、零标准**——角色 `ROLE_MASTER_DATA_APPROVER`（默认只有 admin）打开审批中心点一下"通过"，系统不做任何校验。这在"随时新建、立刻可用"的客户/供应商场景里就是阻塞。G93 用**机器规则**替代这个人。

---

## 2. 自动审批网关：5 关校验

提交（新建 / 编辑 / 遗留草稿 submit）时跑 `validate()`，返回中文错误清单；空=全过=自动通过。

| 关 | 校验 | 判定 |
|---|------|------|
| ① 必填完备 | `VALIDATION[type].required` 列非空 | 客户：名称/类型/归属公司；银行账户：行名/账号/户名/币种 … |
| ② 查重 | `VALIDATION[type].unique`：名称（可限同公司）+ 关键唯一键 | 客户名同公司不重复；供应商税号不重复；银行账号不重复；物料名不重复 |
| ③ 格式规范 | 列名启发式：phone/email/swift 正则 | 电话 6~20 位、邮箱含@、SWIFT 8/11 位 |
| ④ 值域合法 | 币种 ∈ `SYS_CURRENCY` 字典 | currency_code/default_currency/budget_currency |
| ⑤ 引用存在 | 归属公司 ∈ sys_organizations 且 ACTIVE | 不能挂到不存在/未生效的公司 |

- **全过** → 直接 ACTIVE，审计 `operator=AUTO` + `_autoApproved`。
- **不过** → 抛 `自动审批未通过：原因1；原因2…`，前端红框原样显示，用户改完重提。**不进任何队列、不等任何人。**

---

## 3. 行为变化（对比 G92）

| 动作 | G92（人工默认） | G93（自动审批） |
|------|----------------|----------------|
| 新建审批类（客户/供应商/…） | DRAFT → 提交 → 等人审 → ACTIVE | 校验 → **直接 ACTIVE** / 退回 |
| 新建运营类（物料/SKU/…） | 直接 ACTIVE | 校验（含查重）→ ACTIVE / 退回 |
| 编辑关键字段 | 落变更请求 → 等人审 → 应用 | 校验改动列 → **直接生效** / 退回 |
| 编辑扩展字段 | 直接生效 | 直接生效（同样跑格式校验） |
| 谁审批 | admin 人工 | **机器规则**（AUTO） |

**编辑只校验本次改动的列**：容忍历史脏数据，不会因为某个没碰过的旧字段（如老导入的脏电话）把你改备注都卡死。

---

## 4. 关键设计点

- **查重排除自身 + 排除已归档**：`WHERE code <> self AND status <> 'ARCHIVED'`。
- **scopeByCompany**：客户/项目/门店/仓库/司机名按同公司查重（不同公司可同名）。
- **skipEmpty 唯一键**：税号/条码/司机电话非必填，为空则不参与查重。
- **组织/公司不做名称查重**：同名部门在不同上级下合法，只校必填+格式。
- **容错放行**：字典/引用查询异常一律放行不阻断（不让基础设施抖动卡住业务）。
- **SQL 安全**：表名/列名来自服务端 TYPES/VALIDATION 白名单（非用户输入），值全参数化。

## 5. 人工通道的去向

G92 建的 `md_change_requests` 表 + `MD_FIELD_CHANGE` bizType **转为休眠**（不再被默认流程调用），保留作为「未来若某类型/某字段想开人工复核」的现成通道。当前按用户「全自动无例外」一律不启用。

---

## 6. 用户问题逐一答

1. **审批标准是什么？** §2 五关：必填/查重/格式/值域/引用。客观、可复现、无主观。
2. **谁来审批？** 机器（AUTO）。不再需要人。
3. **能改成自动审批吗？** 已改。提交即校验即生效。
4. **重复字段怎么判？** 名称 + 关键唯一键（税号/账号/条码…），见 §2②。
5. **客户/供应商随时新建自动进名单？** 是。新建客户/供应商校验通过即 ACTIVE，立刻可被订单/采购选用。
6. **不合规怎么办？** 当场退回，红框列出每一条原因，改完重提，全程不等人。
