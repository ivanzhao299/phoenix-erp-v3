# Phoenix ERP V3 — Shareholder Runtime Phase 3 规划（股权最终确认与资本口径）

> 规划文档 · **仅在「股权最终确认后」启动**，当前阶段（Phase 2A）不实施。

---

## 启动前提（硬条件）

**孟赛蛋鸡养殖场、万象食品厂的最终股权比例确认后**方可启动 Phase 3。
在此之前，系统采用**实缴口径**（Phase 2A），只记录真实出资，不建立应缴/未缴/差额。

| 项目 | 当前 equity_status | Phase 3 启动条件 |
|------|:------------------:|------------------|
| 东鹏蛋鸡养殖场 | CONFIRMED | 已确认，可优先补录应缴金额 |
| 孟赛蛋鸡养殖场 | PROVISIONAL | 待最终股权确认 |
| 万象食品厂 | PROVISIONAL | 待最终股权确认 |

## Phase 3 内容

1. **股权最终确认**：将 PROVISIONAL → CONFIRMED；锁定各股东最终股比。
2. **应缴金额建立**：按确认股比 × 项目总注册资本，回填 `shr_project_equity.subscribed_capital`。
3. **未缴金额计算**：启用 `unpaid_capital` GENERATED 列（应缴 − 实缴）展示与预警。
4. **出资差额**：按股东汇总未缴差额，生成催缴/补缴清单。
5. **股东结算**：退股/转股/增资的结算流程与凭证。
6. **股权重算**：若按实际出资重新确认股比，重算 equity_ratio 并留痕历史版本。
7. **分红测算**：按确认股比与可分配利润测算各股东分红；分红转投资联动出资台账。
8. **资本账户**：建立股东资本账户（实收资本/资本公积/未分配利润/分红预留）。

## 与 Phase 2A 的衔接

- Phase 2A 已保留 `unpaid_capital` GENERATED 字段（前端隐藏）；Phase 3 直接启用，无需改表结构。
- Phase 2A 的实缴台账 `shr_capital_contributions` 是 Phase 3 应缴/未缴计算的实缴来源。
- Phase 3 启用前，Dashboard 不显示应缴/未缴/差额。

## 风险与原则

- **禁止在股权未确认前建立应缴口径**（避免理论数与事实数混淆）。
- 股权重算须保留历史版本（审计可追溯）。
- 分红测算与资本账户须与 Finance V2 对账后再联动。
